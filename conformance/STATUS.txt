# FigDown conformance — the REASON manifest for conformance/experimental/
#
# WHAT THIS IS
# ------------
# a fixture's status is decided by ONE thing and one
# only: which directory it lives in.
#
#   conformance/cases/         the v0.1 conformance surface — NORMATIVE
#   conformance/experimental/  outside it — EXPERIMENTAL
#
# This file no longer decides that. It records WHY each fixture in
# `experimental/` is outside the surface, one line each, in one auditable
# place. `conformance/run.js` validates the correspondence in BOTH
# directions — a record naming a fixture that is not in `experimental/`
# is a hard error, and a fixture in `experimental/` with no record is a
# hard error — so neither list can silently rot.
#
# WHAT CHANGED, AND WHAT IT COST
# --------------------------------------------
# Until 0.1 this file was a per-case TAG and the 52 fixtures named
# below sat inside `cases/` alongside the normative ones. The reasoning
# recorded here for that choice was explicit — a tag keeps every citation
# by filename valid, while a directory move breaks them — and the
# isolation ruling OVERRULES it: frozen and experimental material must be
# separated at the FILE level, so that a user or an agent who wants
# nothing experimental can ignore whole files rather than filter a list.
# The cost the old note predicted is real and was paid: every citation of
# a moved case by path (DISCREPANCIES.md, the R-entries,
# `spec/migrations.md`, `conformance/README.md`) had to be updated in the
# same batch, and a future status change is now a file move plus a line
# edit rather than a line edit alone. The 0.1 MIGRATIONS entry
# lists the moved names.
#
# The unification also ended a genuine inconsistency: `experimental/`
# already held the `chart` fixtures (700, 701) under a SECOND mechanism —
# a corpus the default run never executed at all. They now run with
# everything else and carry a recorded reason like every other fixture,
# which is why the default TOTAL RUN grew by two while the NORMATIVE
# total did not move. (HISTORICAL, as of 0.1: TOTAL RUN 211 → 213,
# NORMATIVE unchanged at 159. Those are the figures of that release and
# are NOT the current ones — see NO COUNTS LIVE IN THIS FILE below.)
#
# NO COUNTS LIVE IN THIS FILE
# ---------------------------
# This file records REASONS, not totals. Every total the suite has — the
# normative count, the experimental count, the total run, and the
# by-genre / by-construct / both split — is computed from these records
# and from the directory contents on EVERY invocation of:
#
#   node conformance/run.js
#
# Quote that output, never a number typed here. Hand-maintained tallies
# in this file drifted for several releases in a row and were removed at
# 0.1 rather than corrected again; where a number appears below it
# is marked HISTORICAL and dated, and states what a past release CHANGED
# rather than what is true now.
#
# WHAT WAS DEMOTED, AND BY WHAT
# -----------------------------
# `CONSTRUCT-STATUS-TIERS` made the genres `topology`, `flowchart` and `timing`
# (spelled `wave` until 0.1, `TIMING-GENRE-NAMING`)
# EXPERIMENTAL and demoted nine constructs (`threshold` — spelled `guide`
# until 0.1 — `band`, `bundle`,
# `plane`, `path`, `routing`, `text=`, `stroke=`, `plane=`) to
# EXPERIMENTAL. SIX of those nine have since moved: `stroke=` was
# promoted back to NORMATIVE (`STROKE-KEY-STATUS`), `text=`/`color=`
# left the language altogether (`TEXT-COLOUR-KEY-NAMING`, `COLOUR-KEY-STATUS`), `path`/`routing` were
# WITHDRAWN outright (`EDGE-GEOMETRY-CONSTRUCTS`) — the first exercise of the
# withdrawal path `CONSTRUCT-STATUS-TIERS` always allowed — and `plane`/`plane=` were WITHDRAWN
# (`PAINT-ORDER-CONSTRUCT`), the second exercise of it, taking `z-index=` with
# them (the key was legal on `plane` and nowhere else). The demoted set is
# now three — `threshold`, `band`, `bundle` — and none of them is a paint
# key. `bundle` is additionally the first construct to be demoted, kept, and
# then withdrawn FROM ONE GENRE ONLY (`block`, `SCENE-KEYWORD-MEMBERSHIP`) while staying live in
# another (`topology`), which is what per-genre vocabulary makes possible.
# A second implementation may skip
# all of that and still claim v0.1 conformance, so a fixture whose
# SUBJECT is one of them must not be counted in the headline number.
#
# Nothing here changes what a fixture asserts: every fixture in
# `experimental/` still RUNS on a default invocation and still has to
# PASS. Its location decides which bucket it is COUNTED in, nothing else.
#
# THE DEFAULT
# -----------
# `default normative` states the rule for the OTHER directory: every
# `cases/*.fd` is normative, with no per-file record needed. Everything
# below names a fixture in `experimental/`.
#
# THE CRITERION (maintainer ruling)
# ---------------------------------
# A fixture's status follows what it TESTS, not what it happens to USE.
#
#   * A case is EXPERIMENTAL if its header genre is experimental — an
#     implementation restricted to the normative genre surface cannot
#     parse the fixture AT ALL, so it cannot be asked to.
#   * A case is EXPERIMENTAL if it is a dedicated test of a demoted
#     keyword: the demoted construct is the thing under test.
#   * A fixture that merely USES a demoted construct while testing
#     something normative stays NORMATIVE — it stays in `cases/`. Twelve
#     are in this position
#     (112, 115, 209, 214, 215, 233, 259, 301, 304, 305, 306, 307 —
#     115 runs `bundle`, `threshold` and `band` through
#     the generic option-before-label rule (`OPTION-POSITION-PARSING`), which is core lexing;
#     the others are presentation and lexical sweeps touching
#     `extend=`, or running `threshold`/`band`/`bundle`/`timing` through a
#     generic check; 259 is nonetheless
#     experimental below, by its `topology` header). Until 0.3 the
#     same sentence named `plane` and `plane=`/`z=` alongside them, and
#     `115` ran `bundle` under a `block` header: `SCENE-KEYWORD-MEMBERSHIP`/`PAINT-ORDER-CONSTRUCT` withdrew `plane`
#     from the language and `bundle` from `block`, so those writings left
#     `cases/` in that release — `115` grew a `topology` section to keep the
#     `bundle` half of its coverage rather than lose it. Six more embed a
#     `timing` block, itself EXPERIMENTAL, inside a normative-genre document
#     (112, 214, 215, 304, 305, 414). Moving any of them would drag
#     normative coverage of `fill=`, `style=`, the label absent/empty
#     states and the cross-kind id rules out of the surface with them.
#   * `904-errors-retired-keywords` is NORMATIVE, and stayed normative when
#     `path` and `routing` were withdrawn: §10 classifies a
#     retired registration as NORMATIVE (diagnostic), a WITHDRAWN spelling is a
#     retired registration like any other, and the fixture writes the retired
#     spellings in order to be told so. `913-withdrawn-edge-geometry-keys` is
#     normative for the same reason, and it MOVED into `cases/`
#     — it was `913-retired-path-option-keys` in `experimental/`, where it sat
#     only because it hosted the retired keys on a `path` line. With `path`
#     gone the keys have no acceptor at all, the host is a plain `node`, and
#     nothing experimental is left in the fixture. `914-retired-guide-keyword` is EXPERIMENTAL by the
#     opposite reading: it is a dedicated test of the demoted construct's
#     own retirement, and it WRITES `guide` at line start.
#   * OPEN QUESTION — THE CRITERION AND ITS OWN RECORDED
#     EXCEPTIONS NOW DISAGREE, AND THIS IS THE RECORD OF THAT, NOT A RULING.
#     `SCENE-KEYWORD-MEMBERSHIP` withdrew `bundle` from `block`, and the fixtures that USED it as a
#     lexical host kept their coverage by APPENDING a `topology` section
#     rather than deleting the line. ELEVEN normative fixtures now declare
#     one: 115, 118, 119, 123, 214, 215, 304, 306, 804, 905, 906. (Three more
#     declare `flowchart` or `statechart` and predate this release: 801, 802,
#     807.)
#     * AGAINST leaving them in `cases/`: criterion 1 above says a case is
#       EXPERIMENTAL if its header genre is experimental, on the ground that
#       "an implementation restricted to the normative genre surface cannot
#       parse the fixture AT ALL, so it cannot be asked to". Read literally
#       that reaches a fixture with ONE experimental section as surely as one
#       with only experimental sections, and it would move eleven files and
#       move the published normative count with them.
#     * FOR leaving them: criterion 1's ground is about a WHOLE fixture being
#       unparseable, and this file's own gloss on `224` already decides the
#       multi-section case the other way — "its four headers are block/
#       topology/bitfield/flowchart, so the genre criterion does not reach
#       it" — which is why `224` carries `construct=role` alone. `801` and
#       `802` are the same shape and are NORMATIVE. And
#       criterion 3 governs directly: a fixture that merely USES an
#       experimental construct while testing something normative stays
#       normative, and a section is how a multi-genre lexical sweep USES one
#       now that vocabulary is per genre.
#     * What is NOT in dispute: `spec/experimental.md` §E0.1 already records
#       that the skip promise is conditional and enumerates the fixtures that
#       make it so. Whichever way this resolves, that enumeration is the
#       honest statement to an implementer, and it is where the cost is
#       already visible.
#     RESOLVING IT is a maintainer ruling plus eleven file moves plus eleven
#     records here, and it changes a published count — so it does not happen
#     as a side effect of a vocabulary release. It is written down so the
#     next reader finds the QUESTION rather than a rule that quietly stopped
#     being true.
#   * `915-retired-chart-level` is EXPERIMENTAL: `chart` is outside the
#     v0.1 conformance surface entirely (§4.4), so its option key's
#     deletion diagnostic is too.
#   * `387`, `388`, `389`, `395`, `396` are NORMATIVE. They sit in the
#     `38x`/`39x` bands but exercise the `layout` zone itself with `pin`
#     — both core, both normative.
#   * The `bundle`/`plane` demotion (same batch as the rest
#     of `CONSTRUCT-STATUS-TIERS`) moved THREE cases and only three: `331`, `332` and `333`
#     were dedicated `plane` tests written under a `block` header, so
#     nothing but the construct criterion reached them. The other seven
#     dedicated `bundle`/`plane` cases (`271`, `330`, `390`–`394`) were
#     already experimental by their `topology` header and gained a
#     `construct=` reason without changing status, exactly as
#     `330-plane-paint-order` carried both. (HISTORICAL: `330`–`333` were
#     DELETED with the construct — see the `plane` block
#     below. The reading is recorded because it is the criterion, and the
#     criterion outlives the fixtures that illustrated it.)
#     `271`'s subject is read here as the
#     `bundle` member rule (an external id resolving as a member); read
#     as an `external` test instead it would lose the `construct=` half
#     and keep its bucket either way — a one-line edit.
#
# FORMAT
# ------
#   <fixture-basename>  <reason>[,<reason>...]  <note — rest of line>
#
# Blank lines and lines starting with `#` are ignored. Fields are
# whitespace-separated; the note is rest-of-line. (Until 0.1 this
# read "lexed the way FigDown itself lexes `title`"; `title` now takes a
# quoted string, so the comparison no longer holds and the note format is
# stated on its own terms.) Reasons:
#
#   genre=<g>       the header genre is EXPERIMENTAL (spec §10, `CONSTRUCT-STATUS-TIERS`)
#   construct=<k>   the case is a dedicated test of a demoted keyword, OR
# of an EXPERIMENTAL genre-owned keyword —
#                   `construct=role` is the flowchart role vocabulary (`FLOWCHART-ROLE-KEYWORDS`),
#                   which is experimental because its genre is. 224 carries
#                   the reason alone: its four headers are block/topology/
#                   bitfield/flowchart, so the genre criterion does not reach
#                   it, but its SUBJECT is the experimental keyword.
#
# Changing a fixture's status is now a FILE MOVE between the two
# directories plus the matching line edit here. That is more expensive
# than the one-line edit this file used to be, and it is the price of
# file-level isolation; it is stated rather than hidden.
