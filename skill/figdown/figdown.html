FigDown PoC — deterministic text→SVG, draft v0.0

Figures as text — one source, two readers. Edit left, render right. Same source → same SVG, bit-level.

Every GUI action rewrites the text: double-click empty canvas → new node + pin · drag a node → pin at= · arrow keys nudge (Shift = ×10) · drag the corner handle → pin width=/height= · Pin all freezes the live layout into pin lines · double-click a node → rename · Del → delete · fill color → fill= · Link → edge · ⬚ Group → group · multi-section files: layout edits stay in the first section (before the next figdown) · Ctrl+S save · Ctrl+O open · autosave on.
